隐私政策

Privacy Policy · 文档日期：2026-10-21

本政策适用于仅供本人使用的 VMISS Metadata Mount 及本静态说明网站。

1. 应用用途与权限

本应用通过 rclone 在本人管理的 Ubuntu VPS 上提供 Google Drive 只读目录视图。唯一请求的 Google OAuth scope 为：

https://www.googleapis.com/auth/drive.metadata.readonly

本应用可请求文件与文件夹的名称、目录层级、大小、修改时间等元数据，以 Google API 实际返回为准。此权限不授予读取文件内容、编辑或删除文件的能力。本应用不自动下载、同步或预读文件内容。

2. OAuth 令牌与目录元数据

  • 本人使用自有的 Google 桌面 OAuth 客户端，在本人 Mac 上发起授权；Google 处理登录、同意授权及 API 认证。本站不接收 Google 密码或 OAuth 授权信息。
  • 授权令牌，包括用于续期的令牌，保存在本人 Mac 和本人 VPS 的权限受限文件中，仅用于本应用的授权访问及续期。
  • rclone 在挂载运行时向 Google API 请求元数据，并可能在内存中短期缓存目录元数据，以呈现目录视图。
  • 本站不存储或公开令牌、目录元数据或云端文件；本应用不提供公开存储和分享服务。

3. 第三方服务与网站访问

Google 自行处理 OAuth 与 Drive API 请求，相关处理同时受 Google 自身的隐私政策约束。本应用未接入第三方分析、广告或跟踪工具，也不出售个人数据。

本说明网站由 GitHub Pages 静态托管。访问页面时，GitHub 会按照其平台政策处理基础访问日志及相关技术信息。这些托管平台处理与本应用在本人设备上保存的令牌、目录元数据相互独立；本站不嵌入分析脚本或外部跟踪资源。

本应用对 Google API 所获取信息的使用遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。Google 与 GitHub 的平台处理分别见 Google 隐私政策及 GitHub 隐私声明。

4. 保存与安全

令牌在本人设备的权限受限文件中保存，直至本人删除。内存中的目录缓存仅用于运行期间的短期访问，结束挂载进程可释放该进程的缓存。静态托管访问日志的保存由 GitHub 自行管理。

权限限制与只读配置用于减少暴露风险，但不构成绝对安全保证。本人负责维护 Mac、VPS 及凭据文件的访问权限。

5. 撤销授权与删除本地凭据

  1. 进入 Google 账号的“第三方连接”管理页面，找到本应用并撤销其访问权限；具体页面名称以 Google 当前界面为准。
  2. 停止 VPS 上的相关 rclone 挂载服务。
  3. 如需清理，由本人删除 Mac 和 VPS 中保存的本应用令牌及相关私密配置。删除本地凭据与在 Google 端撤销授权应分别完成。

以上操作不删除 Google Drive 中的文件。本应用仅供本人使用，当前未提供公开联系邮箱或公众支持渠道。
